Dual-model oversight:
- Planner/supervisor: mistral-large-latest by default. It creates the initial plan, reviews three-cycle repetition, and performs every-ten-cycle checkpoints.
- Worker: mistral-small-latest by default. It performs normal observation and action decisions to preserve free-tier quota.
- Supervisor reviews can request up to five observation tools, then return a structured ok/intervention directive.
- Navigation settle gate detects URL batches, waits for bounded stabilization, and blocks immediate duplicate URL entry while pages load.
- Interactive terminate returns to the objective prompt; Ctrl+C stops monitors and exits.
